# Card gen improvements
- Add ability to change font for card letters/numbers
  - Allow users to select standard fonts in dropdown.
  - Allow users to upload ttf files to set the font
- Add a slide bar for `parameters` that slides from the default value to +- 50%
- Split suitimages into two sections
  - Suit images inner
  - Suit images outer
    - Outer suit images are placed with the number / letter of the card
    - Inner suit images are placed for the class number card grid of symbols
    - E.g. If the user just specifies spade.png it will go to both outer and inner
      - The user can specify spade.png, spade_inner.png, and spade_outer.png
      - This applies to all suits, spade, club, diamond, heart
- Add input type to parameters
  - number, checkbox, etc
  - In the parameters object, force all sub items to specify `type` of the object
